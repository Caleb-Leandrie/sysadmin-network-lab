# Laboratoires Réseau avec GNS3

## Présentation

Ce dossier regroupe des travaux pratiques de conception, de configuration et de diagnostic de réseaux informatiques réalisés dans un environnement de laboratoire GNS3.

## Objectifs

- Comprendre l'adressage IPv4 et les sous-réseaux.
- Configurer des interfaces réseau sur des équipements Cisco IOS/IOSv.
- Mettre en place le routage IP.
- Vérifier la connectivité entre plusieurs réseaux.
- Diagnostiquer les problèmes de communication.
- Documenter les configurations et les résultats des tests.

## Technologies et outils

- GNS3
- Cisco IOS / IOSv
- IPv4 et TCP/IP
- Commandes Cisco IOS
- Git et GitHub

## Travaux pratiques prévus

1. Configuration des interfaces et adressage IPv4.
2. Vérification de la connectivité réseau.
3. Configuration du routage statique.
4. Analyse et résolution des problèmes de routage.
