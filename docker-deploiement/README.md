# Docker et déploiement d'applications

## Objectif

Mettre en pratique la conteneurisation et le déploiement d'applications à l'aide de Docker.

## Compétences visées

- Création et gestion de conteneurs Docker.
- Configuration des ports et des réseaux.
- Gestion des variables d'environnement.
- Persistance des données avec les volumes.
- Déploiement reproductible avec Docker Compose.
- Diagnostic des services et consultation des journaux.

## Environnement technique

- Linux
- Docker
- Docker Compose
- Git et GitHub

## État du projet

Projet en cours de développement. Les configurations, les commandes utilisées et les résultats des tests seront documentés au fur et à mesure.

## Résultat attendu

Disposer d'une infrastructure conteneurisée fonctionnelle, documentée et reproductible.
