# Administration système Linux

## Objectif

Présenter mes travaux pratiques en administration système Linux et développer mes compétences à travers des exercices concrets.

## Travaux pratiques

- Installation et configuration de Debian Linux
- Gestion des utilisateurs et des groupes
- Gestion des permissions sur les fichiers et dossiers
- Gestion des services système
- Configuration réseau sous Linux
- Diagnostic et résolution de problèmes

## Environnement de travail

- Debian Linux
- Parrot OS
- VirtualBox
- Terminal Linux

## Progression

Les travaux pratiques seront ajoutés progressivement, avec les commandes utilisées, des explications et des captures d'écran lorsque cela sera pertinent.
