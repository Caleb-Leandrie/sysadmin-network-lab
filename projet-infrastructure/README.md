# Projet d'infrastructure — Déploiement des postes par le réseau

## Présentation

Ce projet vise à préparer une infrastructure de déploiement permettant d'installer et de déployer des systèmes sur des postes clients à travers le réseau.

## Objectifs

- Installer et administrer un serveur Debian.
- Mettre en place une solution de déploiement avec FOG Project.
- Comprendre le fonctionnement du démarrage réseau PXE/iPXE.
- Configurer et diagnostiquer les paramètres réseau nécessaires.
- Préparer une machine de référence.
- Capturer une image système et tester son déploiement sur un poste client.

## Environnement technique

- Debian Server
- FOG Project
- VirtualBox
- PXE / iPXE
- DHCP et TFTP
- SSH
- Git et GitHub

## Étapes du projet

1. Préparation du serveur Debian.
2. Installation et configuration de FOG.
3. Configuration du réseau de laboratoire.
4. Préparation de la machine de référence.
5. Capture de l'image système.
6. Enregistrement d'un poste client.
7. Test du déploiement réseau.
8. Vérification du résultat et documentation.
